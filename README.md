# Rafael Ribeiro — Portfolio

## View the portfolio

**[Open the portfolio website](https://raphn.github.io/portfolio/)**

The link above opens the rendered HTML portfolio through GitHub Pages. Opening
`index.html` in GitHub's repository file browser shows its source code instead.
No GitHub account or installation is needed to visit the website.

## Browse the work

- Choose a project card on the homepage to open its presentation.
- Browse the project's images, description, contribution roles and credits.
- Videos have playback controls; press Play to watch them. Playback depends on
  the video format supported by your browser.
- Use **All projects** or **Portfolio** to return to the homepage.
- Individual project-page URLs can be shared directly.

This collection presents selected 3D modeling, materials, rigging, animation,
rendering and other creative projects. New presentations appear as they are
published.

## View a downloaded copy

Download this repository as a ZIP, extract it, and open `index.html` in a modern
browser. Keep the folders together so image, video and stylesheet links work.
You can also serve the extracted folder locally with
`python -m http.server 8000` and visit <http://localhost:8000/>.

## Repository contents

`index.html` is the homepage, `styles.css` contains the presentation styles, and
`projects/` contains the published project pages and selected media. This is the
public presentation site; original project/source files, the local catalog and
private preparation notes are kept separately.
